# 电商视觉工作台：界面改版方向

基线：用户提供的源码导出（文档标题 v1.2.1，内部界面标识 v1.3）。压缩包中的 EXE 与桌面 EXE 的 SHA-256 一致。

## 目标

让用户在首次打开、导入素材、筛选和批量处理时，迅速看清当前状态与下一步操作。保持现有核心流程和文件处理逻辑不变。

## 视觉规范

- 浅色主题采用冷白画布、深灰正文、单一蓝色主操作；深色主题保留相同的信息层级。
- 页面标题、正文、次要说明、辅助标签分为四级。正文优先达到 14px；关键说明不使用低对比度的三级字色。
- 卡片边框、圆角和间距使用统一 token，减少重复的渐变、徽章和装饰性小字。
- 主操作在一个页面只保留一个最强视觉焦点，其余动作用次级样式。

## 页面调整

1. 首页：压缩装饰文案，突出“添加产品”和四个常用工作流；无素材时给明确起步路径。
2. 产品库：无数据时显示居中引导；有数据时系列、网格和检视面板随宽度调整，卡片保持最低可读宽度。
3. 素材资产库：未选择目录、目录为空和筛选无结果分别给对应操作，不留大片空白。
4. PSD 与清洗工具：任务未就绪时把条件写在空状态中，长说明移到辅助位置。

## 布局规则

- 宽窗口显示系列栏、网格、可选检视面板；窄窗口优先保证网格宽度。
- 图片网格按可用宽度自动计算列数，目标卡片宽度不低于约 170px。
- 各页面在 1440×900、1020×680、125% 系统缩放下检查裁切、重叠和文字可读性。

## 验收

- 全局样式在浅色和深色主题均能辨认主次信息。
- 空状态有清楚的标题、解释和直接可执行的按钮。
- 产品库缩窄后不出现工具栏互相遮盖，卡片不被压成不可读的小方块。
- 现有导航、选择文件、筛选和导入信号连接继续工作。
